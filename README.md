# SoraTools

SoraTools est une app web qui regroupe des outils pratiques : conversions, color picker, générateurs de templates et utilitaires développeur.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvre :

```txt
http://localhost:3000
```

## Scripts

```bash
npm start
npm run dev
```

## Tools prévus

- Color picker : HEX, RGB, HSL
- JSON formatter
- Base64 encoder / decoder
- Template generator
- File converter
