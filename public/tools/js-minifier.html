Comment ça marche ?

La minification retire les commentaires et les espaces inutiles pour réduire la taille du fichier JavaScript. Le résultat est plus compact et plus rapide à transférer.

L'option d'obfuscation encode le code minifié dans un petit wrapper d'exécution. Elle rend le code moins lisible, mais ce n'est pas une protection forte : un code côté client peut toujours être inspecté.

L'option « Module ? » conserve les déclarations import et export au niveau racine, valide le code en mode module et évite le wrapper d'exécution pour préserver les modules ES et les usages CommonJS comme require, module.exports ou exports.
