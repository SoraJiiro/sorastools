Conversion

Comment ça marche ?

Les images sont converties avec Sharp. Les vidéos et audios passent par FFmpeg. Les fichiers Word, Excel et PowerPoint sont convertis en PDF avec LibreOffice lorsqu'il est installé sur la machine serveur.

Les conversions PDF → Word, PDF → Excel et PDF → PowerPoint génèrent des fichiers éditables à partir du texte extrait du PDF. Elles sont pratiques pour récupérer le contenu, mais ne conservent pas parfaitement la mise en page d'origine.

La compression garde le même format. Elle compresse les images, audios, vidéos et PDF. Pour les PDF, Ghostscript doit être installé côté serveur.
