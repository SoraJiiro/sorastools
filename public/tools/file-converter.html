Conversion

Comment ça marche ?

Les images sont converties côté serveur avec Sharp. Les vidéos et audios passent par FFmpeg. Les documents Word sont convertis en PDF avec LibreOffice lorsqu'il est installé sur la machine serveur.

La conversion PDF → Word génère un fichier .docx à partir du texte extrait du PDF. Elle est pratique pour récupérer le contenu, mais ne conserve pas parfaitement la mise en page d'origine.
