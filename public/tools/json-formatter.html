JSON

Comment ça marche ?

Le JSON est un format texte utilisé pour représenter des données structurées avec des objets, des tableaux, des chaînes, des nombres et des booléens. Il est très utilisé dans les API web et les fichiers de configuration.

Le formatter analyse le JSON avec JSON.parse(), puis le réécrit avec JSON.stringify(). Cela permet de valider la syntaxe, de rendre le contenu plus lisible ou de le minifier pour le rendre plus compact.
