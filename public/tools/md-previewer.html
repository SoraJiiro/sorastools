Markdown (MD)

Comment ça marche ?

Le Markdown est un langage de balisage léger qui permet de formater du texte en utilisant une syntaxe simple. Il est souvent utilisé pour rédiger des documents, des articles de blog, des README de projets logiciels, etc.

Le Markdown Previewer développé ici utilise le package Node marked pour convertir le texte Markdown en HTML. Le rendu est mis à jour en temps réel à mesure que l'utilisateur saisit du texte dans la zone de saisie.
