Markdown (MD)

Comment ça marche ?

Le Markdown est un langage de balisage léger qui permet de formater du texte en utilisant une syntaxe simple. Il est souvent utilisé pour rédiger des documents, des articles de blog, des README de projets logiciels, etc. L'application Discord laisse les utilisateurs écrire des messages en Markdown, et GitHub l'utilise pour les fichiers README et les commentaires.

Le Markdown Previewer développé ici utilise le package Node marked pour convertir le texte Markdown en HTML et highlight.js pour colorer automatiquement les blocs de code.
