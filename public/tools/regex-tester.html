    Regex
    
        
    Comment ça marche ?
    
      
    

      
    
        Une expression régulière, ou regex, est un motif utilisé
        pour rechercher, valider ou extraire des morceaux de texte. Elle peut
        servir à trouver une adresse email, une URL, une date ou un format
        précis dans une chaîne de caractères. Le Regex sert
        également à valider des entrées utilisateur, comme un mot de passe ou
        un
        numéro de téléphone et ajoute une sécurité supplémentaire s'il est
        ajouté au code serveur qui reçoit ces données.
      
    

      
    
        Le Regex Tester utilise l’objet / classe JavaScript
        RegExp
        pour
        appliquer le motif au texte fourni. Les options comme g,
        i et m permettent respectivement de chercher
        toutes les correspondances, d’ignorer la casse et de gérer le mode
        multiligne.
