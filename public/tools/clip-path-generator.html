Clip-Path

Comment ça marche ?

La propriété CSS clip-path permet de découper un élément en suivant une forme. Avec polygon(), chaque point est défini par une coordonnée X% Y% dans la zone de l'élément. Clip-path est souvent utilisé pour créer des formes personnalisées qui seraient normalement impossible à faire avec les propriétés CSS standards, ce qui est plutôt pratique.

Ce générateur crée automatiquement le CSS à partir des points placés sur la grille. Plus tu ajoutes de points, plus la forme peut être précise.
