Comment ça marche ?

Un fichier .chart décrit les notes, le tempo, les sections et les événements d'une musique pour des jeux comme Clone Hero. L'audio reste séparé : le fichier exporté contient la structure de la chart, pas le morceau lui-même.

Cette première version vise l'édition rapide : notes guitare/basse, BPM constant, Star Power, HOPO forcés, strums forcés, tap notes, lecture synchronisée et export propre.
